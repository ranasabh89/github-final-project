# github-final-project

## Simple Interest Calculator

This project contains a Bash script (`simple-interest.sh`) that calculates simple interest based on user input.

## Details

Simple Interest is calculated using the formula:

    Simple Interest = (Principal x Rate x Time) / 100

## Input Fields

- **Principal**: the initial amount of money
- **Rate of Interest**: the annual interest rate (in %)
- **Time Period**: the duration in years

## Usage

    chmod +x simple-interest.sh
    ./simple-interest.sh

The script prompts for the three values and prints the simple interest.
